# 単発スクリプトの整理（2026-11-13）

実行コードや文書・現行Windowsタスクからの参照が見つからなかった、個別の診断・修復用スクリプトをローカルのOLDフォルダーへ退避しました。実行・削除はしていません。

## 退避対象

| 元ファイル | 用途 |
| --- | --- |
| check_google_data.py | Google OAuth情報の調査 |
| check_oauth_setup.py | OAuth・Site設定の調査 |
| cleanup_duplicate_oauth.py | 重複OAuth設定の削除 |
| debug_login_detail.py | 特定ユーザーのログイン調査 |
| debug_login_issue.py | 特定メールアドレスのログイン調査 |
| fix_tip_markup.py | 特定記事の本文修復 |
| recover_kuwaharata.py | 特定ユーザーの復旧 |
| verify_delete.py | 特定ユーザーの削除確認 |

元の内容を同名でOLD直下に保存しています。移動に伴い相対パスの前提は変わるため、OLD内でそのまま実行しないでください。特に削除・更新処理の再利用時は、DBのバックアップと内容の再確認が必要です。

## 残したもの

アプリ本体、Djangoマイグレーション、テスト、現行の通知・再起動処理、DB、メディア、バックアップ、秘密設定は変更・移動していません。PostgreSQL移行、OAuth初期登録、カテゴリ投入、開発セットアップ用スクリプトは、現行用途が残る可能性があるため維持しました。

## 除外の扱い

- OLDはGit対象外です。既存の追跡済みスクリプトは元位置の削除差分となり、退避先はコミットされません。過去の内容はGit履歴にも残ります。まだコミットしていません。
- VS Codeのエクスプローラー・検索・監視から除外します。ローカルのVS Code設定は既存方針どおりGit対象外です。フォルダーを確認したい場合はエクスプローラーで除外表示を切り替えてください。
- リポジトリルートの本番GitHub ActionsはOLDを除いた一時領域を配備します。ワークスペース内の参考ワークフローでも成果物から除外します。
- 手動ZIP配備は更新した[配備手順](DEPLOY_AZURE.md)に従ってください。任意のツールでフォルダー全体を送る場合、Git除外だけでは配備除外になりません。
- この整理ではAzureへの配備、Gitへのコミット、通知送信は行いません。
